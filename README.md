# dreamLab 営業用HP（静的HTML一式）

株式会社dreamLab 営業用ホームページのデザインを、そのままブラウザで開けるHTMLに書き出したものです。
`index.html` をダブルクリックすると、トップページが開きます。

- 書き出し日：2026年11月2日
- 動作：HTML / CSS / 小さなJavaScriptのみ（フレームワーク・ライブラリは不使用）
- 対応：パソコン・タブレット・スマホ（レスポンシブ。主な切り替え幅は 960px / 760px / 600px）

---

## 2. フォルダ構成

```
dreamLab_HP/
├─ *.html            各ページ
├─ css/
│  ├─ site.css       基本のスタイル（色・文字・余白の変数、部品）
│  ├─ pages.css      ページごとの部品と、デザイン案A（「一本の線」のテーマ）
│  └─ export.css     静的HTMLにしたときの補助（規約タブ・送信ボタン）
├─ js/main.js        スマホメニュー、フォームのご用件切り替え、ブログのタブ、URLコピー
├─ img/              写真（WebP）とロゴ（PNG）
├─ 計測タグと構造化データ.html   公開時に貼るGA4・Clarity・構造化データ
└─ README.md         このファイル
```

## 3. デザインのルール（手を入れるときの目安）

- **色と書体の変数**：`css/site.css` の `:root`。テーマの追加分（線の位置など）は `css/pages.css` の「デザイン案A」ブロック冒頭の `:root`。
- **書体**：Google Fonts の3書体（見出し＝しっぽり明朝、本文＝Zen角ゴシック New、欧文・数字＝Cormorant Garamond）。
- **「一本の線」**：各セクション左側の縦線は `main > section::before` で引いています。セクションの縦見出し（例：「お悩み」）は `.vlabel`。
- **テーマの効く範囲**：デザイン案Aのスタイルは `:where(.site:not(.da):not(.db))` の中だけで効きます。ページ全体を `<div class="site">` で包んでいるのはそのためです。外さないでください。
- **ファーストビュー**：トップ・AI経営支援・販路開拓・教育は `.hero--balanced`（写真を6:5にして画面の高さに収め、本文とボタンを写真の高さの中で上下中央に置く）。教育の写真は先生まで入るよう `.hero__photo--wide`（4:3・右寄せ）にしています。
- **動き**：スクロールで線が伸びる・写真がふわっと出る動きは、CSSの `animation-timeline` を使っています。未対応のブラウザでは動きなしで表示され、OSの「視差効果を減らす」設定がオンの人にも動きは出ません。
- **改行**：日本語が単語の途中で切れないよう、`.phrase`（`word-break: auto-phrase`）と `.ib`（まとまりを1行に保つ）を使っています。

## 4. 公開前に必要な作業

### 必ず対応するもの
1. **お問い合わせフォームの送信先**
   今は `inquiry.html` の送信ボタンで `inquiry-thanks.html` に移るだけの見本です。フォーム送信サービス（formrun、Googleフォームなど）またはサーバー側の処理につないでください。
   項目の name：`type`（ご用件）, `company`, `name`, `email`, `message`, `agree`、隠し項目 `utm_source` / `utm_campaign`。
   `inquiry.html?type=session` のように開くと、ご用件が選ばれた状態になります（session / pilot / market / education / consult / free）。各ページのボタンはこの形でつないであります。
2. **LINE公式アカウント**：友だち追加のURL（`href="#"` の箇所）とQRコード画像（「QRコード」の枠）。友だち追加の特典PDF「まるで自分が書いたようなメール作成方法」の用意。
3. **SNSのリンク**：フッターの Facebook / Instagram / LINE（`href="#"`）。
4. **計測タグ**：同梱の「計測タグと構造化データ.html」を、書いてある場所に貼ってください（GA4の測定ID・ClarityのプロジェクトID・公開ドメインを差し替え）。
5. **会社情報の地図**：`company.html` の「Googleマップ」の枠に、Googleマップの埋め込みコードを入れてください。

### 中身が決まったら差し替えるもの
- **お知らせ**（`index.html`）：［日付］［カテゴリ］
- **ブログ・関連記事**：［記事タイトル］［公開日］とアイキャッチ画像の枠。記事ができるまでは、関連記事の枠を非表示にするのがおすすめです。
- **代表の動画**：トップと90分セッションの「動画で見る（約1分）」は、今はブログ一覧へのリンクです。動画ができたら、その記事か動画のURLに変えてください。
- **AI経営支援のよくある質問**：［対応エリアと、エリア外の交通費の扱いを記入］
- **ブログ記事**：`blog-post.html` は記事の型です。記事ごとにこのファイルを複製して使ってください。

### あるとよいもの
- ファビコン、SNSで共有されたときの画像（`og:image`）。各ページの `<head>` にタイトルと説明文は入れてあります。
- 90分セッションのカード決済（Stripeの決済リンク）。特定商取引法の表記は `tokusho.html` にあります。

## 5. 画像について

- 写真はすべて、HP全体で色調（彩度を少し落として暖色寄り）を揃えたうえでWebPに変換しています。
- `img/market-statement-packing.webp`（販路開拓ページ「Small Start, Big World」の写真）は、Canvaで生成したイメージ写真です。実績や事例の写真としては使わないでください。
- `img/case-hairmake.webp` はイメージ写真です（ページ上にも「※写真はイメージです」と表示しています）。
- 子どもが写っている写真は、掲載の了承を得たものだけを使ってください。
