# dreamLab Website — Modern Astro Architecture & Hosting Guide

All page copy, layout, and styling remain **100% unchanged**, now organized into a clean `src/` → `dist/` Astro architecture with extensionless URLs and full technical SEO.

## Project Structure

```text
dreamLab_HP/
├─ src/
│  ├─ layouts/BaseLayout.astro    # Shared SEO <head>, canonical, OG/Twitter, JSON-LD, Header/Footer
│  ├─ components/                 # Header, Footer, StickyBar
│  ├─ data/                       # Site metadata & Schema.org JSON-LD builders
│  ├─ pages/                      # Extensionless page routes (/ai-support, /company, /blog, etc.) + sitemap.xml.ts + 404.astro
│  ├─ styles/                     # site.css, pages.css, export.css (bundled & minified into dist/_astro/)
│  └─ scripts/main.js             # Menu toggle, inquiry form switch, UTM tracking, blog tabs, share copy
├─ public/
│  ├─ img/                        # Static images served from /img/...
│  ├─ robots.txt
│  ├─ _headers                    # Cloudflare Pages / Netlify headers
│  └─ _redirects                  # Redirect legacy *.html URLs -> clean URLs
├─ dist/                          # Production build output (generated by `npm run build`)
├─ astro.config.mjs
├─ server.js                      # Production Node.js server serving dist/ + POST /api/inquiry
├─ Dockerfile                     # Multi-stage Docker build
├─ vercel.json                    # Vercel config (output: dist)
└─ netlify.toml                   # Netlify config (publish: dist)
```

## Local Development

```bash
npm run dev       # Astro dev server at http://localhost:3000
npm run build     # Build optimized static output into dist/
npm start         # Serve production dist/ at http://localhost:3000
```

## Real Hosting Options

### Option A: Cloudflare Pages / Netlify / Vercel (Recommended)
- **Build command:** `npm run build`
- **Output / Publish directory:** `dist`
- **Optional environment variables:**
  - `SITE_URL=https://dreamlabltd.jp` (your real domain for `canonical`, `og:url`, and `sitemap.xml`)
  - `PUBLIC_GA_ID=G-XXXXXXXXXX` (Google Analytics 4 ID)
  - `PUBLIC_CLARITY_ID=XXXXXXXXXX` (Microsoft Clarity Project ID)

### Option B: Docker / Render / Railway / Fly.io / VPS
- Uses `Dockerfile` or `npm run build && npm start` (`node server.js` serving `dist/`).
- Health check endpoint: `/healthz`
- Inquiry API endpoint: `POST /api/inquiry` (optional `INQUIRY_WEBHOOK_URL`).

## Pre-Launch Checklist (External Accounts / Links)
1. **Domain:** Set `SITE_URL` (and update `public/robots.txt` sitemap domain if different from `https://dreamlabltd.jp`).
2. **Inquiry Form:** Connect `src/pages/inquiry.astro` `<form>` to Formspree / Web3Forms / Netlify Forms or `/api/inquiry` (`method="post"`).
3. **LINE & SNS Links:** Replace `href="#"` and `QRコード` placeholder in `src/components/Footer.astro` and LINE sections.
4. **Analytics:** Set `PUBLIC_GA_ID` and `PUBLIC_CLARITY_ID` environment variables at build time.
